# Sekin stem testi uchun fayllar

Bu papkaga ochiq litsenziyali (CC0) audio qo'ying. Fayllar repoga qo'shilmaydi.

- `piano.wav` — yakka pianino yozuvi (baraban, bas va vokal bo'lmasin).
- `drums.wav` — baraban sikli.

Bor bo'lsa va Demucs o'rnatilgan bo'lsa, test kutadi: pianino yozuvida `drums.energy_share < 0.05`, baraban siklida `drums.energy_share > 0.5`.

Fayllar yoki Demucs bo'lmasa test `skip` bo'ladi.
